Method

Read the paper

PanoVLN follows language instructions using 360° RGB observations. It combines panoramic semantics with PanoVGGT geometry features, then uses prediction confidence to decide how much of an action sequence to execute before observing again.

4BQwen3.5 backbone

98Ktraining trajectories

800HM3D training scenes
