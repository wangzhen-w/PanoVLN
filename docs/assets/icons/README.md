# Interface and brand icons

Phosphor icons are copied without path changes from the [official repository](https://github.com/phosphor-icons/core), commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e`. They are MIT licensed; retain [the complete notice](licenses/PHOSPHOR-MIT.txt) when redistributing them. `phosphor/regular` contains interface icons; `phosphor/duotone` contains larger feature symbols.

The PanoVLN mark in `../brand/logo.svg` uses the Phosphor Panorama Duotone icon with its fill set to `#086b63`. `../brand/wordmark.svg` combines that same unmodified icon geometry with the text PanoVLN. The icon is a shared library asset, not an exclusive PanoVLN design.

`brands/github.svg` and `github-white.svg` are official [GitHub logo downloads](https://brand.github.com/foundations/logo), for GitHub project/profile links. `brands/huggingface.svg` and `huggingface-monochrome.svg` come from [Hugging Face brand assets](https://huggingface.co/brand). Preserve their proportions and approved colors; platform marks remain owned by their respective organizations.

`brands/arxiv.svg` comes from [Simple Icons](https://github.com/simple-icons/simple-icons), commit `d4e6ba93e48f178898707f0145ec285f28b64b38`. Simple Icons uses CC0, but its [disclaimer](licenses/SIMPLE-ICONS-DISCLAIMER.md) distinguishes the library license from individual brand rights. Follow the [arXiv name and logo guidance](https://info.arxiv.org/brand/brand-guidelines.html); this asset does not imply an arXiv publication or endorsement.

See `sources.json` for exact download URLs, original sources, SHA-256 hashes, and per-asset notes. These third-party notices cover these graphics only and do not select a license for the PanoVLN software.
